# UI Components Directory

This directory contains modular atomic UI components for the RightsTrack frontend interface:

- `Navbar.jsx`: Global header navigation with responsive branding and intake call-to-actions.
- `CaseCard.jsx`: Dashboard summary card for individual cases with dynamic status pills.
- `CitationBadge.jsx`: Interactive citation badges that link directly to source statutes.
- `DeadlineTimer.jsx`: Real-time countdown timer computed from deterministic date calculations.
- `LegalDisclaimer.jsx`: Mandated statutory disclaimer displayed across document generation flows.
